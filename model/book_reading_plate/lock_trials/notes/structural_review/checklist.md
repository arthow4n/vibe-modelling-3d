# Full-load audit checklist

- [x] Read design skill and inspect authoritative joint geometry.
- [x] Establish explicit book, self-weight, support, handling and material assumptions.
- [x] Obtain primary PETG reference and distinguish assumed allowance from certified properties.
- [x] Measure actual CAD sections and inspect 3D sectioned geometry.
- [x] Calculate full-load bending, socket prying, shear, withdrawal and stiffness screens.
- [x] Compare optimistic and partial load sharing; explain solid-infill limitation.
- [x] Withdraw unsupported print recommendations and preserve historical evidence.
- [ ] Resolve original 10 mm thickness constraint and redesign the failed load path.
- [ ] Qualify replacement geometry, manufacturing and physical limits before approving it.
- [ ] Commit and push audit; report actual result at handoff.
