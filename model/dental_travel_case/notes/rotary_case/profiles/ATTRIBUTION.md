# Profile attribution

The wheel preset derives from the [indexed rotary process](../../rotary_refinement/profiles/ATTRIBUTION.md), itself derived from the shared Orca/Qidi diagnostic profiles. It retains their AGPL-3.0 licensing and upstream attribution. This revision only disables primary supports for the tapered wheel; the evaluator still probes automatic supports separately.
