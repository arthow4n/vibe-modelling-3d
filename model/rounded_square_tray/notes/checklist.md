# Modelling and verification checklist

- [x] Request, reference image, repository instructions, and evaluator inspected.
- [x] Intended use and dimensional assumptions documented.
- [x] Upright orientation fits the 250 × 250 × 250 mm practical envelope.
- [x] No fit/mechanism uncertainty warrants a separate test piece.
- [x] Parametric exterior loft, cavity, and edge treatments implemented.
- [x] Final CadQuery validity, topology, bounds, and views checked.
- [x] Representative alternate parameter configuration checked.
- [x] Final STEP/STL exported together and independently verified.
- [x] Final generic FDM review and PrusaSlicer smoke slice completed.
- [x] Print instructions, provenance, limitations, and print status recorded.
- [x] Relevant diff reviewed; commit and push tracked at handoff.
